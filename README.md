# Smart Academic Management System (SAMS)

## 📌 About the Project

This project contains Python programs developed for a **Smart Academic Management System (SAMS)**.
The programs demonstrate basic academic management tasks such as environment checking, student registration, grade calculation, data validation, and student-course management.

## 📂 Programs Included

### 1. `Lab1.py` – Development Environment Check

* Displays the Python version.
* Displays the operating system and platform.
* Shows the Python executable path.
* Checks whether Python 3.11 or higher is installed.
* Displays a SAMS welcome message.

### 2. `Lab2.py` – Student Registration

* Takes student details such as name, roll number, age, CGPA, and semester fee.
* Validates age and CGPA.
* Creates a student record.
* Displays a registration summary.

### 3. `Lab3.py` – Grade Engine

* Converts marks into grades.
* Uses grade points to calculate Semester GPA.
* Displays the grade report for each subject.
* Shows whether the student has passed or has a backlog.

### 4. `Lab4.py` – Data Validation

* Validates student roll numbers.
* Validates email addresses.
* Validates phone numbers.
* Cleans and standardizes student records.

### 5. `Lab5.py` – In-Memory Repository

* Stores student records.
* Maintains a course catalogue.
* Manages student course enrollment.
* Assigns faculty members to courses.

## ▶️ How to Run

1. Install **Python 3.11 or higher**.
2. Clone this repository:

   ```bash
   git clone <your-repository-link>
   ```
3. Open the project folder.
4. Run any program:

   ```bash
   python Lab1.py
   ```
5. Similarly, run:

   ```bash
   python Lab2.py
   python Lab3.py
   python Lab4.py
   python Lab5.py
   ```
